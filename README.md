# 搜索排序异常排查 Agent Demo

这是一个脱敏后的业务 Agent 设计示例，用于展示如何将一线工单、业务排查 SOP、数据查询工具和标准化报告生成流程结合起来，辅助排查搜索/列表场景下的排序异常、曝光下降、流量波动等问题。

本项目基于真实实习场景中的 Agent 设计思路整理，但已删除和替换所有公司内部系统、数据库表名、接口地址、密钥、产品 ID、看板 ID、真实工单和业务敏感信息。当前仓库仅用于展示 Agent 设计方法，不连接任何真实公司系统，也不包含真实业务数据。

## 项目背景

在内容、商品或服务供给类平台中，搜索/列表页的排序结果可能因为供给状态、库存/可售情况、流量策略、排序因子变化、实验策略调整等原因出现排名下降、曝光异常或流量波动。传统排查依赖人工查看多个系统、整理原因、再回复业务方，流程重复且容易遗漏。

本项目模拟一个“搜索排序异常排查 Agent”，用于根据用户提交的工单信息，完成问题范围判断、关键信息提取、排查路径规划、模拟数据查询、Case 匹配和报告生成。

## Agent 目标

该 Agent 的目标不是替代人工决策，而是辅助业务同学完成标准化初筛和排查整理：

- 判断问题是否属于搜索/列表排序异常范围
- 提取对象 ID、业务场景、问题时间、异常表现等关键信息
- 根据排查 SOP 规划检查路径
- 调用模拟数据查询工具获取证据
- 匹配常见异常 Case
- 输出结构化排查报告和答复草稿
- 避免在没有工具结果的情况下编造结论

## 核心能力

- **范围识别**：判断工单是否属于 Agent 可处理范围
- **信息抽取**：从工单描述中提取排查所需字段
- **流程规划**：按照标准 SOP 组织排查步骤
- **工具调用设计**：通过模拟 MCP 工具表示数据查询能力
- **Case 匹配**：基于常见问题类型生成初步判断
- **报告生成**：输出标准化排查报告、建议操作和回复草稿
- **安全约束**：不编造数据、不暴露内部系统、不上传真实敏感信息

## Agent 架构

| 模块 | 说明 |
|---|---|
| Prompt | 定义 Agent 的角色、目标、排查流程和输出规范 |
| Skill | 封装“搜索排序异常排查”这一业务能力 |
| Tool / MCP | 表示 Agent 可以调用的数据查询工具，本项目使用模拟工具描述 |
| Case Library | 沉淀常见异常类型和判断逻辑 |
| Harness | 在真实平台中负责调度模型、工具调用、状态记录和报告输出；本 Demo 仅展示设计结构 |

## 项目边界

- 本项目不连接真实公司系统
- 本项目不包含真实数据库表名、接口地址或密钥
- 本项目不包含真实对象 ID、商家信息、工单内容或业务数据
- 本项目中的 Case、工单和报告均为虚构示例
- 本项目重点展示 Agent 的设计思路，而不是提供可直接运行的企业系统

## 适用场景

该设计方式可以迁移到其他业务排查类 Agent，例如：

- 商品流量异常排查
- 搜索结果异常排查
- 广告投放效果异常排查
- 内容推荐策略异常排查
- 客服工单自动分流与答复草稿生成
